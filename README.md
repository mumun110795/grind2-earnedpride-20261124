## About this entry

This entry is a single line of prose, carried in a small TypeScript program that does nothing fancy with it. The scene is deliberately ordinary and close to home: an older person, a familiar household task, and a long stretch of quiet repetition behind one small success. The pride is not announced anywhere in the line — it comes from the effort the reader can feel in the detail, and from a difficulty that has finally, for once, stopped getting in the way. The program simply checks that the line stays within the required length and on one line, then writes it out as-is.

## Run it

```sh
node main.ts
```

By default the program writes `entry.txt` into `/output`. To write somewhere else, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/my-output node main.ts
```

The output directory is created if it does not exist yet, and the file inside it will contain the single entry line as UTF-8 text.
